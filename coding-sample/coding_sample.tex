{\Large\bfseries Stata Coding Sample}\hfill Orlando Valladares

This coding sample presents the validation and preferred event-study estimation layer from my senior seminar project on Hurricane Mitch and municipal nighttime lights in Central America. The complete project and replication package are available at \href{https://github.com/orlando-valladares/mitch-nightlights-replication}{github.com/orlando-valladares/mitch-nightlights-replication}.

My GitHub also includes replication packages for recent Guatemalan and Honduran drought reports that I have been disseminating to help channel funding into the region in response to the severe 2026 El Ni\~no drought.

The code below runs on the real analysis panel distributed with the repository. It checks the panel structure, applies a pre-treatment sample rule, estimates the 64- and 50-knot two-year event studies with municipality and year fixed effects, clusters inference by municipality, and exports machine-readable results. The omitted period is 1996--1997.
